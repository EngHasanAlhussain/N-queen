# Original submission

`Application.py` in this folder is the code as submitted for the KFUPM
Introduction to Artificial Intelligence coursework in 2021 — unchanged,
except for the explanatory header comment that was added on top of it
before the rest of this repo was refactored. It still runs on its own
(`python legacy/Application.py`), but it's kept here purely for historical
reference; the actively maintained version is the `n_queens` package at
the repo root. See the top-level README for what changed and why.
